# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| main    | Yes       |

## Report a Vulnerability

Do not open a public issue for security problems.

Open a private security advisory at:

https://github.com/RP2/gh-vault/security/advisories/new

Include the following in your report:

1. A description of the vulnerability.
2. Steps to reproduce the issue.
3. The potential impact.
4. A suggested fix, if you have one.

## Scope

This policy covers gh-vault application code. It does not cover third-party dependencies. Report dependency issues to the upstream maintainer.

## Maintenance

This project is maintained on a best-effort basis. Security fixes are prioritized but may take time.
